# Jerusalem Stone Group Website

Complete downloadable copy of the Jerusalem Stone Group website.

## Open the website

1. Extract the ZIP file.
2. Keep the folder structure unchanged.
3. Open `index.html` in a modern web browser.

No installation or web server is required.

## Main files

- `index.html` — website content and page structure
- `styles.css` — colors, typography, layout, and responsive styling
- `script.js` — mobile navigation behavior

## Asset folders

- `assets/images/` — logos, company photographs, and stone slab photographs
- `assets/videos/` — reserved for website video files

The current website does not use any videos, so the videos folder contains an information file only.

## Important

If an image or video is renamed, update its matching path in `index.html`.
